\subsection{Definition of Terms}
\begin{itemize}
\item Factor Analysis - A statistical technique used to uncover underlying latent factors in a set of observed variables. 
\item Latent variables -Variables that are not directly observed but rather inferred from other variables that are observed.
\item Independent variables - Variables that are manipulated or changed to measure to the effect of that change on the outcome variable.
\item Dependent variables -variables whose variation is being studied
\item Structural equation modeling - This is a multivariate statistical technique that is used to analyze the structural relationship between measured variables and latent constructs
\item Observed variables - Refers to the data that has been measured and recorded
\end{itemize}
